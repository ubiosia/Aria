# requirements.txt — ARIA, core mínimo ejecutable (Fase 3, Punto 1)
#
# ---------------------------------------------------------------------
# Por qué este archivo NO fija versiones exactas ("==")
# ---------------------------------------------------------------------
# tecnico/instalacion.md lo documenta con cita textual (sección 5):
#
#   "Instalar las dependencias principales sin fijar versiones exactas
#   — el intento original con versiones fijas de `chromadb` y
#   `langchain-chroma` generó un conflicto de dependencias irresoluble.
#   Dejar que el gestor de paquetes resuelva la compatibilidad por sí
#   solo evitó el problema."
#
# Y es una de las "cinco cosas que no se repetirían" del Capítulo 11
# (historia/11_epilogo.md): "Fijar versiones exactas de dependencias
# sin una razón real para hacerlo [...] resuelto, finalmente, dejando
# que el propio gestor de paquetes decidiera qué versiones convivían
# bien entre sí, en vez de forzar una combinación elegida a mano sin
# haberla probado."
#
# Por eso este archivo usa mínimos (">=") donde hay algo que verificar,
# y ningún número donde no lo hay — nunca "==". Los mínimos marcados
# [PyPI, 03/09/2026] se confirmaron contra PyPI en esa fecha al escribir
# este archivo; NO son una cita de un manual de sesión (ninguna versión
# exacta de estos paquetes está documentada ahí). El resto de los
# paquetes se deja sin ningún mínimo especificado, por no haber nada
# que citar — instalar la versión que pip resuelva como compatible.
# ---------------------------------------------------------------------
